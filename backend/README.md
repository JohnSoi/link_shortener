# LinkShortener

API сервис для создания коротких ссылок.

## Структура проекта

* ```alembic``` - миграции и ее настройки.
* ```app``` - основной код приложения.
* ```tests``` - тесты.

## Важные моменты

* Применение миграций

Для применения миграций используется отдельный сервис ```migrations```. Его запуск позволяет
применить на БД сервиса все миграции, которые были созданы.
