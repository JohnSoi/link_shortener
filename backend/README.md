# LinkShortener

API сервис для создания коротких ссылок.

## Структура проекта

* ```alembic``` - миграции и ее настройки.
* ```app``` - основной код приложения.
* ```tests``` - тесты.

## Важные моменты

* Применение миграций

Для применения миграций используется отдельный сервис ```migrations```. Его запуск позволяет
применить на БД сервиса все миграции, которые были созданы.

* Создание миграций

Для создания миграций необходимо выполнить команду из контейнера. 
Для подключения к консоли контейнера используется команда:
```bash
docker exec -it <название контейнера:link_shortener_backend> bash
```

После подключения к контейнеру необходимо выполнить команду:
```bash
alembic revision --autogenerate -m "<название миграции>"
```
